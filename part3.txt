In DVD.checkout(), super() lets me use the checkout() method of MediaItem, the parent class, so I don't have to write the same checkout logic again in DVD. I just call it, and if the checkout worked, I print "Handle with care: Do not scratch the disc." and return the same message that MediaItem gave. If we change MediaItem.checkout() later, like adding a due date, DVD and Book get the change automatically because they call the parent's method. If I had copied the code instead, I would have to change it in every class, and I think it would be easy to forget one.
